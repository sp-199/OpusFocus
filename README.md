# OpusFocus

A Granola-style AI note taker: record a meeting, get a transcript, then searchable notes, action items with evidence, and a grounded summary. Course project for AIPSD F26.

- Design Review: [`docs/DESIGN-REVIEW.md`](docs/DESIGN-REVIEW.md) · Spec: [`docs/spec.md`](docs/spec.md) · Team: [`TEAM-CONTRACT.md`](TEAM-CONTRACT.md)
- HW1 features: [`hw1/sp-199`](hw1/sp-199) search · [`hw1/Avto30`](hw1/Avto30) action items · [`hw1/KurdGela`](hw1/KurdGela) summary
- Tests: `pytest hw1/<username>` (one folder at a time) · Golden set: `python evals/run_golden.py`
- Tools (HW2): [`docs/tool-contracts.md`](docs/tool-contracts.md) · `pip install -r requirements.txt && pytest` · MCP server: `OPUSFOCUS_USER=u-nino python serve.py`
